Executive Summary

FAVE aims to transition Grab from an asset-heavy model to an asset-light partnership, leveraging third-party (3P) fleets to solve ride-hail supply constraints.

Fleet Partner Pain Points

A. Onboarding Friction

Offline matching via spreadsheets, slow vehicle-driver pairing, repeated operational touchpoints

B. Visibility Gap

Where are my vehicles? Are they working? Are drivers generating risk? Are they actually working for Grab?

C. Asset Recovery

Painful repossession when drivers abscond; need credible remote immobilization and location trace

D. Trust & Governance

Fleet concerns about data boundaries, separation vs rental commercial teams, contractual-grade access controls

Key User Flows

1. Vehicle Onboarding

Register vehicle → Bind device → Assign to fleet → Start tracking

2. Real-time Monitoring

Map view → Filter by status/fleet → Click vehicle → View details/trace/video

3. Alert Handling

Receive alert → Acknowledge → Investigate → Take action → Resolve

4. Fleet Configuration

Create fleet → Draw geofences → Assign operators → Set alert rules

5. Immobilization

Locate vehicle → Safety check → Confirm action → Execute → Audit log

6. Video Evidence

Select event → Pull footage → Review → Export for dispute
